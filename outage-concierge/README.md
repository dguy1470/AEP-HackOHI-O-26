# AI Outage Concierge (Hack/OHIO 2026 prototype)

Files
- index.html      Ready to open: the full app with data embedded (no server needed).
- template.html   App source (HTML/CSS/JS). Contains the /*DATA*/ placeholder.
- app_data.json   Compact, anonymized data the app uses (generated by prep.py).
- prep.py         Reads the challenge shapefiles + matched_upstream.txt, builds features,
                  fits the risk model, exports app_data.json.
- build.py        Merges template.html + app_data.json into index.html.

Rebuild from raw data
1. pip install pyshp pandas numpy scipy scikit-learn
2. Unzip the challenge files so you have: Data1/, Data2/, matched_upstream/matched_upstream.txt
   next to prep.py (the original zips are not included here because of size).
3. python prep.py && python build.py

Key assumptions (also shown in the app)
- Risk label: damage recorded within 400 m of a premise in the Feb 2025 storm (AUC ~0.64, coarse screen).
- Restoration hours come from the STORMS sheet; wire/switch/recloser are composites.
- Travel 30% and non-productive 40% are placeholders (indirect-labor file was not provided).
- Coordinates are rounded to ~400 m, IDs are hashed, no names or addresses are shown.
